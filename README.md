# C 罗 Siuuu 桌宠

Windows 透明桌面宠物：点击 C 罗，他会起跳转身、背身亮出 7 号球衣并播放 Siuuu 庆祝声音。支持拖动、调整大小和音量。

![动画预览](Preview/庆祝动画.gif)

## 使用

下载完整项目并解压，双击 `启动C罗.cmd`。右键桌宠可调整设置或退出。需要 Windows 10/11 和 .NET Framework 4.8。

`效果预览.html` 可在浏览器中预览带声音的动画；源码和构建说明位于 `Source`。

人物图像由 AI 生成，音频来自第三方公开音效站。音频来源与使用权说明见 [素材来源](素材来源.md)；公开分发前请确认使用权。本项目为非官方趣味作品。
